# Результаты синтеза P3 (AWS F2 / VU47P-3, 8×8, out-of-context)

Выжимка из `results/synth/*.rpt` (сырые репорты не версионируются — тяжёлые/шумные;
здесь зафиксированы ключевые числа как доказательная база). Прогон: Vivado 2025.2,
part `xcvu47p-fsvh2892-3-e`, период 1.5 нс, массив 8×8, `synth_design -mode out_of_context`.

## Тайминг (`timing_summary.rpt`) — ЗАКРЫТ

| Метрика | Значение | Смысл |
|---|---|---|
| **WNS** | **+0.242 нс** | setup закрыт (≥0) |
| **WHS** | **+0.052 нс** | hold закрыт (частотой не лечится — тоже ок) |
| TNS / THS | 0 / 0 | 0 нарушений из **11088** endpoints |
| **f_max** | **~795 МГц** | = 1 / (1.5 − 0.242) нс |

**Критический путь** — route-bound (микроархитектура на пределе DSP):
```
Source:  g_row[7].g_col[5].u_pe/a_out_reg[7]/C          (fabric FDCE)
Dest:    g_row[7].g_col[7].u_pe/acc_reg/DSP_A_B_DATA_INST/A[21]   (ВНУТРИ DSP48E2)
Logic Levels: 0     Data Path Delay: 0.989 нс  (logic 6.9% / route 93.1%)
```
Приёмник — вход DSP: MAC-регистры сели в AREG/BREG/MREG/PREG. Логики между
регистрами нет (0 levels), 93% задержки — провод → дальше только placement.

## Ресурсы (`utilization.rpt`)

| Ресурс | Использовано | Из | % |
|---|---|---|---|
| **DSP48** | **64** | 9024 | 0.71 |
| **CLB LUT** | **16** | 1 303 680 | <0.01 |
| **CLB FF** | **384** | 2 607 360 | 0.01 |
| BRAM / URAM | 0 / 0 | 2016 / 960 | 0 |

**DSP = 64 = число PE** (8×8) → ресурс-прокси P2 «1 MAC = 1 DSP» подтверждён синтезом.
Почти пустой fabric (16 LUT / 384 FF) = **весь MAC-датапат упакован в DSP** (эффект
синхронного сброса — см. [report_analysis.md](report_analysis.md), worked example).

## Питание (`power.rpt`) — почему это НЕ perf/watt

| | Вт |
|---|---|
| Total On-Chip | 3.565 |
| **Dynamic (логика)** | **0.152** |
| **Device Static** | **3.413** (**96%**) |
| Confidence | Medium |

**96% — статика всего VU47P** при утилизации 0.7%. Динамика нашей логики — всего
0.15 Вт. Делить throughput на 3.565 Вт нельзя: получишь «эффективность» простаивающего
кристалла, а не акселератора. Честный perf/watt = загруженный чип + замер под нагрузкой.

## Источники (честность)
Всё выше — **синтез Vivado (P3)**, не замер на кремнии. Латентность тайла измерена
в симуляции (P2). On-silicon `PASS` на F2 (P4) — отложен (нужен AWS FPGA-доступ).
